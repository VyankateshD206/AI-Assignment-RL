01 / FORMULATION

A practical problem, defined as an MDP.

STATE · ACTION · REWARD

Two rooms have different heat exposure and class schedules. During a shared power restriction, only one AC may fit. Can a policy anticipate classes and keep both rooms comfortable without wasting energy?

Environment

A day is divided into decision intervals. Outdoor air, sunlight and occupants add heat; AC removes it. Room 1 has more solar gain and less thermal inertia.

T′ = T + Δt / C × (outdoor + solar
                  + occupants + fan − AC)

A fan adds motor heat. Its assumed airflow benefit is represented separately in the comfort proxy.

MDP observation · 17 features

  • Both room temperatures and current occupancy
  • Next class time and expected occupancy per room
  • Outdoor temperature, solar input and cyclical time
  • Current / next power cap and time to change
  • Previous AC states

Scaled numerical inputs; coarse bins for Q-learning. The observation summarizes the day and is an approximate MDP state.

Action · 16 joint combinations

Room modeACFan
0OffOff
1OffOn
2OnOff
3OnOn

a = 4 × room_1_mode + room_2_mode

Actions above the power cap are masked during selection and learning targets.

Reward · four penalties

r = −(wE × energy + wD × discomfort
      + wF × worst room + wS × switching)

Discomfort is squared deviation outside the comfort band, weighted by occupancy. Empty rooms have no discomfort penalty. AC state changes are penalized.

The worst-room term encourages fair allocation; it does not guarantee long-term equality.

Model parameters and assumptions

Loaded from Python configuration. No real-building calibration, humidity, ventilation or compressor minimum run times. The fan offset is an assumed proxy, not a validated comfort model.

Edit a JSON config and restart with python gui.py --config configs/custom.json --models for baseline exploration. Changed physical configurations require matching trained checkpoints. Changing reward weights alone does not retrain a policy.

Presentation note “We define the state, action, transition and reward first. Then we learn a policy and compare it with rules on the same environment.”

03 / LEARNING & EVALUATION
From experience to a learned policy.
Q-LEARNING + DQN

 
Q-learning · a table of action values
Q(s,a) ← Q(s,a) + α [target − Q(s,a)]
target = r + γ max Q(s′, feasible a′)
Bin the state, explore feasible actions with ε-greedy, and update one table entry per transition. Unvisited states have zero values; sparse coverage can lead to poor behavior.
DQN · approximate the same values
17 inputs → 64 ReLU → 64 ReLU → 16 Q-values
replay → minibatch → Huber loss → Adam
Store experience, sample past transitions, and fit a neural Q-function. A target network stabilizes targets. Both algorithms use zero bootstrap at day-end.

 
Actual saved training run
Raw exploratory training returns from training.csv. This is saved training history, not live training or proof of generalization.
How to train and change parameters
python train.py --algo q_learning --episodes 300 --seed 0 --output outputs/q_new
python train.py --algo dqn --episodes 300 --seed 0 --output outputs/dqn_new
python train.py --algo dqn --config configs/custom.json --episodes 300 --seed 0 --output outputs/dqn_custom
Use fresh output directories. Physical parameters and reward weights are JSON fields. Learning rate, discount, replay and network settings currently require Python source changes. Train again after changing the learning task or objective, then restart the GUI to load the new policy.
--no-timetable removes explicit next-class inputs. --no-fairness removes the worst-room penalty. Use matching seeds to study each contribution.

 
Same-day baseline comparison
Thermostat, timetable pre-cooling, rotating priority and loaded agents receive the same generated inputs. The scenario and seed below come from the decision screen.
Compare energy at similar comfort. One day illustrates behavior; reportable results require held-out days and independent training seeds. Power-cap violations are prevented by masking, not learned safety.
